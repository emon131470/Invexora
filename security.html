SECURITY

How accounts are protected

✉️

Email code login

Sign-in uses a one-time code sent to your email, so there is no password to steal or reuse.

🔒

Private data

Database rules make sure you can only read your own deposits, balances and referrals.

🧮

Server-side rules

Balances and approvals are calculated on the server, not in your browser, so they cannot be edited by users.

👤

Admin review

Deposits and withdrawals need an administrator's approval and the action is recorded.

STAY SAFE

Protect your account

Guard your code

Never share your email login code with anyone, including people who say they are support.

Check the address

Only sign in on the official site address, and bookmark it.

Report problems

If something looks wrong, contact us through the Contact page.
